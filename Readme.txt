MedimonGame.jar をダウンロードし，MedimonGame.jar が置かれているディレクトリにて以下のコマンドを実行してください．

java -jar MedimonGame.jar {server/{IP adress}/{localhost}} {port no.}

• server : サーバーモードで起動します．
• IP adress : クライアントモードで起動し，接続先の IP アドレスを指定します．
• localhost : クライアントモードで起動し，接続先を localhost に指定します．
• port no. : サーバーモードで起動する場合は，接続を待ち受けるポート番号を指定します．
例：java -jar MedimonGame.jar server 1100

詳細は，medimon.pdfのp.21~24をご確認ください．
